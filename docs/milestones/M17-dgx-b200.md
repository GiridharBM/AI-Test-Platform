# Milestone 17 — NVIDIA DGX B200

Status: **PLANNED — NOT IMPLEMENTED**

## Scope

M17 investigates and implements GPU-accelerated AI inference on NVIDIA DGX B200 infrastructure.

## Planned Investigation Areas

### DGX B200 Deployment

- NVIDIA DGX B200 hardware access and configuration
- Operating system and driver requirements
- CUDA compatibility verification
- NVIDIA Container Toolkit installation and validation

### GPU Access

- GPU visibility inside Docker containers
- NVIDIA runtime configuration
- GPU resource allocation and scheduling
- Multi-GPU support

### AI Inference

- Local/private model serving with GPU acceleration
- Open-source coding LLMs via PyTorch / Hugging Face Transformers
- Model loading and inference pipeline
- Batch inference and streaming

### Resource Allocation

- GPU memory management
- CPU/GPU resource isolation
- Concurrency limits
- Performance monitoring

### Performance Benchmarking

- GPU-accelerated test execution
- Inference latency measurement
- Throughput optimization
- Comparison with CPU-only baseline

### Privacy Considerations

- Local inference (no external API calls)
- Data residency requirements
- Model storage and versioning
- Audit logging

## Acceptance Criteria

Before M17 is considered complete:

1. DGX B200 driver and CUDA compatibility verified
2. NVIDIA Container Toolkit working in Docker
3. GPU visible inside backend container
4. At least one LLM model loaded and serving on GPU
5. Inference latency measured and documented
6. Privacy guarantees maintained (no external calls)
7. Performance benchmarked against CPU-only baseline
8. Documentation updated with verified DGX setup

## Dependencies

- NVIDIA DGX B200 hardware access
- NVIDIA Container Toolkit
- CUDA toolkit
- Docker with NVIDIA runtime support
- Sufficient GPU memory for target models

## Out of Scope

- Multi-node distributed inference
- Model training (inference only)
- Cloud GPU instances (DGX only)
- Custom model fine-tuning
